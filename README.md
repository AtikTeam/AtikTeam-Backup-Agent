# atikteam-backup-agent

Connects to the AtikTeam backup API, maintains a local database of the
files, downloads the ones that changed, expires old versions, and
provides a web interface to browse the backups.

Learn how to use with [AtikTeam online documentation](https://www.atikteam.com/en/doc/page/backup).

Consultez la [Documentation AtikTeam en
Français](https://www.atikteam.com/fr/doc/page/backup).
